## 推荐学习顺序

1. 先看 [进制转换.md](./进制转换.md) 掌握进制基础。
2. 看 [大小端之分.md](./大小端之分.md) 理解字节序。
3. 深入看 [虚拟地址空间.md](./虚拟地址空间.md) 与 [进程、线程、协程.md](./进程、线程、协程.md) 了解内存与并发模型。
4. 看 [TCP协议-三次握手与四次挥手.md](./TCP协议-三次握手与四次挥手.md) 理解网络连接。
5. 工程实践看 [缓存相关.md](./缓存相关.md) 与 [QPS、TPS、并发用户数、吞吐量关系.md](./QPS、TPS、并发用户数、吞吐量关系.md)。
