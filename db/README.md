## 学习路径建议

### MySQL

1. **安装与环境**：`安装-二进制Linux` / `安装-二进制Win` → `安装-用户` → `安装-配置`
2. **SQL 基础**：`表库语句`（建库建表 DDL）→ `增删改查`（DML，含完整可运行示例）
3. **进阶原理**：`索引` → `事务` → `事务-锁` → `Explain语句分析`
4. **实用补充**：`相关函数` → `Json基础` → `导入导出` → `建表习惯`

### Redis

1. **安装与环境**：`安装` → `基本配置`
2. **指令入门**：`基本指令使用`（string / list / set / zset / hash / geo / bitmap）
3. **进阶原理**：`持久化RDB` → `持久化-AOF` → `主从` → `集群`
4. **应用实战**：`缓存雪崩-缓存穿透-缓存击穿`（面试常问的缓存三大问题）

> 版本提示：命令随版本有变化，如 Redis 5+ 用 `replicaof` 替代 `slaveof`、`SET NX` 等价 `SETNX`；MySQL 注意 5.7 与 8.0 的默认认证/JSON 差异。
