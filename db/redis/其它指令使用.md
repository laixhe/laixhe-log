# Redis 其它指令

## 查看内存信息

```bash
127.0.0.1:6379> info memory
```

## 保存数据（持久化）

> `SAVE` 会阻塞服务器；`BGSAVE` 在后台 fork 子进程保存，不阻塞。生产环境用 `BGSAVE`。

```bash
127.0.0.1:6379> SAVE      # 阻塞式保存 => OK
127.0.0.1:6379> BGSAVE    # 后台保存 => Background saving started
```

## 查看主/从复制信息

```bash
127.0.0.1:6379> info replication
```

## 读取服务器配置参数

```bash
127.0.0.1:6379> CONFIG GET dir        # 查看数据目录
127.0.0.1:6379> CONFIG GET maxmemory  # 查看最大内存限制
```
