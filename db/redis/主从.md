# Redis 主从复制

> 版本提示：`slaveof` 是旧命令（Redis 5 之前），新版本统一用 `replicaof`，两者作用相同。

## 主服务器（master）

```bash
# 主服务器只需设置密码（可选）
requirepass <password>
```

## 从服务器（slave）

```bash
# 从服务器配置主服务器地址：replicaof <主库ip> <主库端口>
replicaof 192.168.1.101 6379

# 主库设置了 requirepass 时，从库要连上主库，需要配主库的密码
masterauth <password>

# 从库与主库失去连接或复制进行中，是否继续响应客户端请求（默认 yes）
replica-serve-stale-data yes

# 从库默认只读（yes）
replica-read-only yes
```

## 查看复制状态

```bash
info replication
```

## 主从复制中的 key 过期问题

> Redis 的设计：**只有主库负责删除过期的 key**，从库不自行处理过期，而是等主库发送 DEL 命令后同步删除。
>
> 所以从库上可能短暂读到「主库已过期但尚未同步删除」的 key —— 这是正常现象，过一会儿就会被同步掉。
