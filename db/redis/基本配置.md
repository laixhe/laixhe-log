# Redis 基本配置（redis.conf）

> 以下配置项按 redis.conf 的常见顺序列出，`配置项 值` 就是写入配置文件的内容。

```bash
# 1. 守护进程方式运行（后台运行）
daemonize yes

# 2. 指定 pid 文件位置
pidfile /var/run/redis.pid

# 3. 指定端口
port 6379

# 4. 绑定的主机地址（只允许该 IP 访问；127.0.0.1 仅本机）
bind 127.0.0.1

# 5. 客户端闲置多少秒后关闭连接（0 表示关闭该功能）
timeout 0

# 6. 日志级别：debug / verbose / notice / warning（默认为 notice）
loglevel verbose

# 7. 日志记录方式，默认为标准输出。
#    如果 Redis 以守护进程方式运行，而这里又配置为标准输出，日志会被发送到 /dev/null（丢失）
logfile stdout

# 8. 数据库数量（默认 16 个，编号 0~15，默认使用第 0 个）
databases 16

# 9. 指定本地数据库存放目录
dir ./

# 10. 连接密码（默认关闭，生产环境建议开启）
requirepass password

# 11. 保护模式（默认为 yes；yes 时只允许本机或 bind 白名单访问）
protected-mode no

# 12. 同一时间最大客户端连接数（默认 10000）
maxclients 128

# 13. 指定 Redis 最大内存限制（单位 MB / GB），超限后按 maxmemory-policy 策略处理
maxmemory 512mb

# 14. 内存超过 maxmemory 后的处理策略：
#     volatile-lru       利用 LRU 算法移除「设置过过期时间」的 key
#     volatile-random    随机移除「设置过过期时间」的 key
#     volatile-ttl       优先移除「即将过期」的 key
#     allkeys-lru        利用 LRU 算法移除「任意」key
#     allkeys-random     随机移除「任意」key
#     noeviction         不移除任何 key，写命令直接返回错误
#     注意：以上策略下，如果没有合适的 key 可驱逐，写命令依然会返回错误
maxmemory-policy allkeys-lru

# 15. 包含其它配置文件（引入其它 conf）
include /path/to/local.conf
```
