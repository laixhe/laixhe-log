# Redis 数据类型与指令速查

> 命令格式：`命令 参数`；示例中的 `=>` 后面是 Redis 返回的结果，方便你对照验证。

## 服务与连接

### 启动 Redis 服务

```bash
redis-server [--port 6379] [redis.conf]
```

### 连接 Redis 客户端

```bash
redis-cli [-h 127.0.0.1] [-p 6379]
```

### 停止 Redis 服务

> 在客户端中（提示符形如 `127.0.0.1:6379>`）直接输入 shutdown 即可

```bash
127.0.0.1:6379> shutdown
# 或者
redis-cli shutdown
```

### 清除数据

```bash
# 清除当前数据库
127.0.0.1:6379> flushdb     # => OK

# 清除全部数据库的内容
127.0.0.1:6379> flushall    # => OK
```

### 切换数据库

> Redis 默认有 16 个数据库（0~15），连接时默认使用第 0 个

```bash
127.0.0.1:6379> SELECT 3    # => OK
```

### key 通用操作

```bash
# 获取所有键（pattern 支持通配符，生产环境慎用 keys *）
127.0.0.1:6379> keys *       # => 1) "test"

# 获取键总数
127.0.0.1:6379> dbsize       # => (integer) 1

# 判断 key 是否存在：存在返回 1，不存在返回 0
127.0.0.1:6379> exists test  # => (integer) 1

# 查询键类型
127.0.0.1:6379> type test    # => string

# 删除键：返回删除成功的个数
127.0.0.1:6379> del test     # => (integer) 1
```

### 过期时间

```bash
# 秒：expire key seconds；毫秒：pexpire key milliseconds
127.0.0.1:6379> expire test 60      # => (integer) 1（设置成功返回 1；key 不存在返回 0）
127.0.0.1:6379> pexpire test 60000

# 绝对时间戳：expireat key 时间戳（秒）；pexpireat key 时间戳（毫秒）
127.0.0.1:6379> expireat test 1611546039
127.0.0.1:6379> pexpireat test 1611546056454

# 查看剩余生命周期：ttl 秒；pttl 毫秒
127.0.0.1:6379> ttl test            # => (integer) 60
# 注意返回值：-1 表示永久有效（没设过期）；-2 表示 key 不存在
```

## string（字符串）

```bash
# 添加/修改：新值会覆盖旧值
127.0.0.1:6379> set test xxx        # => OK

# 读取
127.0.0.1:6379> get test            # => "xxx"

# 可选参数（可组合使用）：
#   EX 秒 / PX 毫秒  设置过期时间（SET key v EX 10 等价于 SETEX key 10 v）
#   NX 仅 key 不存在时才生效（等价于 SETNX key v）——常用于「分布式锁」
#   XX 仅 key 存在时才生效
```

## list（列表）

> 双向链表：lpush 从左边插入、rpush 从右边插入，最新插入的都在各自一侧的最前面。

```bash
# 添加（左边/右边）
127.0.0.1:6379> lpush list_key A    # => (integer) 1
127.0.0.1:6379> rpush list_key B    # => (integer) 2

# 移除（左边/右边），并返回被移除的元素
127.0.0.1:6379> lpop list_key       # => "A"
127.0.0.1:6379> rpop list_key       # => "B"

# 按区间取（下标从 0 开始；0 -1 表示取全部）
127.0.0.1:6379> lrange list_key 0 1 # => 1) "B" 2) "A"
127.0.0.1:6379> lrange list_key 0 -1

# 列表长度
127.0.0.1:6379> llen list_key       # => (integer) 2
```

## set（集合）

> 无序、元素不能重复（重复添加返回 0）。

```bash
127.0.0.1:6379> sadd set_key A      # => (integer) 1
127.0.0.1:6379> sadd set_key B      # => (integer) 1
127.0.0.1:6379> sadd set_key A      # => (integer) 0（已存在）

# 移除元素
127.0.0.1:6379> srem set_key A      # => (integer) 1

# 获取所有元素（无序）
127.0.0.1:6379> smembers set_key    # => 1) "B" 2) "A"

# 随机获取元素：不带数量取 1 个，带数量取 n 个
127.0.0.1:6379> srandmember set_key

# 随机删除一个元素并返回
127.0.0.1:6379> spop set_key

# 集合大小
127.0.0.1:6379> scard set_key       # => (integer) 1
```

## zset（有序集合）

> 和 set 一样元素不重复，但每个元素关联一个 double 类型分数（score），Redis 按分数**从小到大**排序。

```bash
127.0.0.1:6379> zadd zset_key 1 B   # => (integer) 1
127.0.0.1:6379> zadd zset_key 2 A   # => (integer) 1
127.0.0.1:6379> zadd zset_key 3 C   # => (integer) 1

# 移除元素
127.0.0.1:6379> zrem zset_key B     # => (integer) 1

# 按下标区间取（默认从小到大）
127.0.0.1:6379> zrange zset_key 0 -1              # => 1) "A" 2) "C"

# 按分数区间取（-inf 负无穷 ~ +inf 正无穷，从小到大）
127.0.0.1:6379> zrangebyscore zset_key -inf +inf

# 反序取（从大到小）
127.0.0.1:6379> zrevrange zset_key 0 -1

# 成员个数
127.0.0.1:6379> zcard zset_key      # => (integer) 2
```

## hash（哈希）

> 类似「对象」：一个 key 下挂多个 field-value 字段。

```bash
127.0.0.1:6379> hset hash_key user_name laixhe     # => (integer) 1
127.0.0.1:6379> hset hash_key user_password 123456 # => (integer) 1

# 移除某个 field
127.0.0.1:6379> hdel hash_key user_password        # => (integer) 1

# 取指定 field 的值
127.0.0.1:6379> hget hash_key user_name            # => "laixhe"

# 取全部 field 和 value（成对返回）
127.0.0.1:6379> hgetall hash_key                   # => 1) "user_name" 2) "laixhe"

# field 个数
127.0.0.1:6379> hlen hash_key                      # => (integer) 1
```

## Geospatial（地理位置）

> 本质是存到 zset 里（score 是经纬度编码），所以 zset 的命令（如 ZREM）对 geo 也适用。
> 有效经度 -180 ~ 180，有效纬度 -85.05112878 ~ 85.05112878。

```bash
# 添加：geoadd key 经度 纬度 成员
127.0.0.1:6379> geoadd china:city 116.413384 39.910925 beijing   # => (integer) 1
127.0.0.1:6379> geoadd china:city 113.271431 23.135336 guangzhou # => (integer) 1
127.0.0.1:6379> geoadd china:city 113.582555 22.276565 zhuhai    # => (integer) 1

# 取成员的坐标
127.0.0.1:6379> geopos china:city beijing zhuhai

# 两个成员之间的距离（单位默认 m；可跟 km / mi / ft）
127.0.0.1:6379> geodist china:city guangzhou zhuhai      # => "1033354.0946"（约 1033 km）

# 以给定经纬度为中心，找半径内的成员
# 可选：WITHCOORD 带坐标 / WITHDIST 带距离 / COUNT n 只显示前 n 个（按距离递增）
127.0.0.1:6379> georadius china:city 113.582555 22.276565 500 km

# 以已有成员为中心，找半径内的成员
127.0.0.1:6379> georadiusbymember china:city zhuhai 500 km
```

## BitMaps（位图）

> 用位存储 0/1 状态，适合签到、在线状态等场景。

```bash
# 设置某一位的值：setbit key offset value
127.0.0.1:6379> setbit sign 0 1     # => (integer) 0（返回该位原来的值）
127.0.0.1:6379> setbit sign 1 0
127.0.0.1:6379> setbit sign 4 1

# 读取某一位
127.0.0.1:6379> getbit sign 4       # => (integer) 1

# 统计所有位中值为 1 的个数（可按字节区间统计）
127.0.0.1:6379> bitcount sign       # => (integer) 2
```

## 事务与监视

```bash
# multi 开启事务 → 依次入队命令 → exec 一起执行；discard 取消事务
127.0.0.1:6379> multi
127.0.0.1:6379> set k1 v1
127.0.0.1:6379> set k2 v2
127.0.0.1:6379> exec              # => 1) OK 2) OK

# watch key 监视（乐观锁）：exec 前 key 被别的客户端改动，则事务不执行
# unwatch 取消监视
```
