# 数据增删改查（DML）

> 约定：表名、字段名用反引号 `` ` `` 包住（与 MySQL 关键字区分），字符串值用单引号 `'`。

## CRUD 基本语法

```sql
# 插入
INSERT INTO `tableName` (`字段名`, ...) VALUES (value1, ...);

# 删除
DELETE FROM `tableName` [WHERE ...];

# 更新
UPDATE `tableName` SET `字段名` = value1, ... [WHERE ...];

# 查询
SELECT `字段名`, ... FROM `tableName` [WHERE ...];
```

## 完整示例（可照着跑）

```sql
-- 建表
CREATE TABLE `student` (
    `id` INT PRIMARY KEY AUTO_INCREMENT,
    `name` VARCHAR(20),
    `age` INT
);

-- 插入
INSERT INTO `student` (`name`, `age`) VALUES ('laixhe', 18), ('张三', 20);

-- 查询
SELECT * FROM `student` WHERE `age` > 18;      -- 结果：id=2 name=张三 age=20

-- 更新
UPDATE `student` SET `age` = 19 WHERE `name` = 'laixhe';

-- 删除
DELETE FROM `student` WHERE `name` = '张三';
```

## 条件（WHERE）

```sql
# 条件（结果为 bool）
WHERE ...

# 集合内【查这三个】
IN (1, 2, 3)

# 在某个范围内【查 1 到 3 的】
BETWEEN 1 AND 3

# 模糊匹配：% 通配任意个字符，_ 通配单个字符
LIKE '%xxx%'

# 对结果集分组
GROUP BY `字段名`

# 对分组后的结果筛选（不能再用 WHERE）
HAVING ...

# 对结果集排序
ORDER BY `字段名`

# 限制条数：① 跳过（偏移量）几条 ② 取几条
LIMIT 0, 3
```

> SQL 执行顺序：`WHERE -> GROUP BY -> HAVING -> ORDER BY -> LIMIT`

## LIMIT 的两种写法（等价）

```sql
SELECT * FROM `xxx` LIMIT 1, 3;        -- 跳过第 1 条，取第 2、3、4 条
SELECT * FROM `xxx` LIMIT 3 OFFSET 1;  -- 效果同上
```

## 子查询

```sql
-- WHERE 子查询：内层查询的结果作为外层的比较条件
SELECT * FROM `tableName` WHERE `id` IN (SELECT `id` FROM `other`);

-- FROM 子查询：内层查询的结果集作为外层的临时表（必须起别名）
SELECT * FROM (SELECT `name`, `age` FROM `student`) AS `t` WHERE `t`.`age` > 18;

-- EXISTS 子查询：内层结果为真/假，作为外层的条件
SELECT * FROM `tableName` t WHERE EXISTS (SELECT 1 FROM `other` o WHERE o.`id` = t.`id`);
```

## 连接（JOIN）

```sql
-- 内联接：只取两边都匹配的数据
SELECT * FROM `a` INNER JOIN `b` ON `a`.`id` = `b`.`id`;

-- 左联接：以左边表为准，右边查不到补 NULL
SELECT * FROM `a` LEFT JOIN `b` ON `a`.`id` = `b`.`id`;

-- 右联接：以右边表为准，左边查不到补 NULL
SELECT * FROM `a` RIGHT JOIN `b` ON `a`.`id` = `b`.`id`;
```

## UNION 合并结果集

> 把多条 SQL 的结果集合并成一个，要求**列数相同**（列名可以不一致）。

```sql
SELECT `name` FROM `a` UNION SELECT `name` FROM `b`;
```

## 查询结果写回表

```sql
-- 从查询结果更新：update + join
UPDATE `a` INNER JOIN (SELECT `id`, `age` FROM `b`) AS `c` ON `a`.`id` = `c`.`id`
SET `a`.`age` = `c`.`age`;

-- 从查询结果新增：INSERT ... SELECT（子查询后面不要再加 AS 别名）
INSERT INTO `a` (`col1`, `col2`) SELECT `col1`, `col2` FROM `b`;
```

## NULL 处理

```sql
SELECT * FROM `tableName` WHERE `status` IS NULL OR `status` = 0;
```

## 分析性能瓶颈

```sql
EXPLAIN SELECT * FROM `tableName` WHERE ...;  -- 查看执行计划
```
