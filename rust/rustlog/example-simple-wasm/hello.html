🦀 Rust → WebAssembly Hello World

这个页面演示如何在浏览器里调用 Rust 编译出来的 WASM 函数：

  • Rust 端：#[wasm_bindgen] pub fn greet(name: &str) -> String
  • JS 端：import('./pkg/example_simple_wasm.js').then(m => m.greet('World'))

试一试：在下面输入你的名字，WASM 会返回一句问候

(结果会显示在这里)

📦 构建步骤（你需要先完成才能看到效果）

# 1. 添加 wasm32 目标架构（只需一次）
rustup target add wasm32-unknown-unknown

# 2. 安装 wasm-pack（只需一次）
cargo install wasm-pack

# 3. 在 example-simple-wasm 目录下构建（生成 pkg/ 目录）
cd example-simple-wasm
wasm-pack build --target web --out-dir ./pkg --out-name example_simple_wasm

# 4. 启动一个本地静态服务器（直接 file:// 打开不行，浏览器出于安全限制禁止加载本地 .wasm）
#    如果你有 Python：
python -m http.server 8080
#    然后浏览器打开：
#    http://localhost:8080/example-simple-wasm/hello.html
