# 低多边形殖民模拟（simple_mini_3d_tree_low_poly）

一个纯代码生成的 3D 模拟经营小游戏：程序化地形上分布着树木和浆果丛，
你指挥 3 名殖民者采集资源、建造房屋与工坊、安排工作，让聚落慢慢运转起来。

- 引擎：**Bevy 0.19** + Rust（edition 2024）
- 不依赖任何外部模型 / 贴图：地形网格、资源点、建筑、角色全部用代码生成
- 教学定位：综合运用本仓库学过的 3D 渲染、程序化网格、关系组件、异步任务、
  资源系统、UI、输入、Gizmos 调试绘制等知识点

## 运行方式

```bash
cargo run --example simple_mini_3d_tree_low_poly
```

可选参数：

```bash
# 线框模式（观察网格结构，便于理解程序化地形）
cargo run --example simple_mini_3d_tree_low_poly -- --wireframe

# 隐藏 HUD 界面（只看世界）
cargo run --example simple_mini_3d_tree_low_poly -- --hide-ui
```

## 玩法速览

1. **开局**：中央有一座仓库（含 40 木材、20 食物）和 3 名殖民者。
2. **采集**：殖民者会自动去砍树（获取木材）、采浆果（获取食物）并搬回仓库。
3. **建造**：按数字键选中建筑类型，移动鼠标预览，左键放置。
   - 建筑需要先由殖民者**搬运木材**到位，然后**花时间建造**才完工。
4. **工作**：建造「伐木屋 / 采集屋 / 劈柴场」后，殖民者会自动被分配职业去上班；
   点击建筑可用 + / - 调整岗位数量。
5. **生存**：殖民者会饿（饱食度 < 50 自动回家吃饭），房子提供居住与存粮。
6. **目标**：**人口达到 10** 即达成。人口会在「公共食物充足 + 有空房」时每 10 秒自动增长一名
   （每栋房屋容量 5）；也可用调试台快速添加殖民者。
7. **引导**：屏幕顶部会按「伐木屋 → 采集屋 → 房屋 → 冲人口」分步提示下一步做什么。

| 显示 / 隐藏 UI | `F1` |
| 操作说明面板 | `H` |
| 调试控制台 | `` ` ``（反引号，Esc 键下方） |

| 平移视角 | 鼠标中键拖拽 |

## 资源与经济

| 资源 | 单位占用容量 | 来源 | 用途 |
| --- | --- | --- | --- |
| 木材 Wood | 10 | 砍树（每棵 24） | 建造材料 |
| 食物 Food | 1 | 采浆果（每丛 20） | 殖民者进食 |
| 柴火 Firewood | 1 | 劈柴场：1 木材 → 5 柴火 | 仓库储量（演示用） |

容量规则：仓库（中央 1000 / 普通 4000）、殖民者每次搬运 10 容量（木材 1 根 / 食物 10 份）。

## 模块架构

```
main.rs            程序入口：组装插件、处理命令行参数（--hide-ui / --wireframe）
├── building/      建造系统
│   ├── mod.rs     插件注册，串起输入 → 预览 → 放置 → 生命周期
│   ├── components.rs   建造相关组件与数据：Blueprint / Footprint / Workplace / Housing…
│   ├── state.rs        BuildState（当前选中、旋转角、农场角点）与 PlacementIssue 枚举
│   ├── input.rs        快捷键：选建筑、旋转、网格吸附、Esc / 右键取消
│   ├── placement.rs    建造预览（合法/非法高亮）与放置
│   ├── lifecycle.rs    蓝图 → 建筑的生命周期：搬运木材、建造进度、出生视觉体
│   ├── geometry.rs     WorldGeometry：记录所有占用多边形、保留的入口、导航脏区
│   └── polygon.rs      多边形几何工具：面积、凸性、相交、点在多边形内
├── terrain.rs      程序化地形：分形值噪声生成高度、森林/浆果区分类、资源点分布
├── world.rs        世界初始化：材质、地形网格、资源节点、中央仓库、初始殖民者
├── colonist.rs     殖民者 AI：需求（饥饿）、住房分配、岗位分配、寻路、采集、搬运、建造
├── navigation.rs   寻路系统：NavGrid 分块网格 + 双向 A* + 异步路径规划 + 路径缓存
├── farm.rs         农场：角点多边形校验、覆盖层网格、作物网格排布
├── resources.rs    资源与库存：Inventory 容量规则、公共库存汇总
├── selection.rs    点选系统：鼠标拾取地面 + 优先命中，Gizmos 高亮选中对象
├── camera.rs       轨道相机：右键旋转 / 中键平移 / 滚轮缩放
├── simulation.rs   模拟时钟：暂停与速度倍率（空格键）
├── ui.rs           HUD：资源栏、建造按钮、选中面板、岗位调节、FPS
├── debug_console.rs 调试台：加资源/加人、快速建造、线框开关
├── types.rs        游戏数据定义：资源/建筑/施工种类、建筑属性表、坐标换算
└── math.rs         数学工具：射线求交地形（步进 + 二分）、xz 平面距离
```

## 教学要点（对应 Bevy 0.19 知识点）

- **组件式渲染 API**：`Mesh3d` / `MeshMaterial3d<StandardMaterial>`（不再用旧的 `PbrBundle`）
- **关系组件**：`ChildOf` 建立建筑视觉体与逻辑体的父子关系
- **程序化网格**：手动构造 `Mesh`（顶点 / 法线 / UV / 顶点色 / 索引），用于地形与农场覆盖层
- **异步任务**：`AsyncComputeTaskPool` + `Task` 把寻路放到后台线程，避免卡顿
- **Gizmos**：选中高亮、建造预览辅助线
- **资源系统**：`Resource` 存放世界状态（地形种子、几何占用、模拟时钟、选择状态）
- **输入**：`ButtonInput` + 累积鼠标输入 `AccumulatedMouseMotion/Scroll`
- **线框调试**：`WireframePlugin` + `RenderDebugFlags`（0.19 新版 API）
- **单元测试**：78 个测试覆盖地形确定性、资源分布、几何判定、库存容量、生命周期等
