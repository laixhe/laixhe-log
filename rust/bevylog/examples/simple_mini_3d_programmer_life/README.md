# 程序员求职生存模拟

一款以当代就业环境为背景的日程养成模拟游戏：你将扮演一名计算机专业学生，
从大三暑期找实习开始，经历投简历、笔试、面试、通勤、实习转正、秋招、毕业入职，
一路走到职场日常——或者倒在半路上。

- 引擎：**Bevy 0.19** + Rust（edition 2024）
- 以 3D 45度角俯视的低模场景
- 场景与 UI 全部用**命令式** API（`commands.spawn` + `with_children`）构建，没有用声明式场景宏 `bsn!`，方便新手像读普通 Rust 代码一样阅读
- 可以参考 examples 目录下的用例

## 视觉风格

- **纸张背景**：启动时程序化生成暖黄纸张纹理（噪点 + 纸屑斑点 + 边缘晕影），不依赖任何贴图文件
- **红色牌匾横幅**：顶部居中悬挂，金边红底显示章节与周数
- **HUD 手账卡片**：存款金锭药丸、精力/心态/健康三条圆形字章进度条（顶部高光、低于 30 变红）、五枚技能标签药丸
- **对话场景**：金边圆角相框立绘 + 姓名牌 + 「正在与你对话」标签 + 纸质气泡卡片
- **城市世界**：一张 120×120 连续大城市（十字主路 + 环路 + 支路组成的道路网，沿街一排排低模小楼街区）

## 城市地图玩法

- **一张连续大城市**：五个区域错位分布在市中心四周——家（城西）/ 校园（城南）/ 食堂（城东）/ 公司（城北）/ 公园（城东北），
  市中心 (0,0) 是交通枢纽。宽大的十字主路贯穿全城，环路围出 CBD，支路把每个区域接到主路上；校园周边还有夜市 / 观景台 / 涂鸦墙等探索点；
  主路与环路两侧还有一排排沿街小楼，走起来像一座真正的城市。区域间直接走过去（跨区不会传送），或到站点乘车
- **点击走动**：点击地面让主角走过去（自动翻转朝向 + 走路起伏）；点击热点走到跟前自动触发行为
- **碰撞与绕行**：墙 / 建筑 / 路灯 / 围栏 / 桌椅等家具都带碰撞盒，点击或自动行为会先用网格 A* 算出绕行路径，再沿路径走过去——不会穿墙穿建筑，贴墙还能自然滑动；走不过去（被墙围死）会提示「走不过去…」后停下；巡逻 NPC 同样用 A* 绕行，不穿建筑
- **家**：床（补觉）/ 书桌（刷算法）/ 书堆（背八股）/ 厨房（做饭）/ 电脑（投简历）/ 手机（找人聊聊）/ 电视（追剧回心态）/ 浴室（洗澡回精力健康）/ 冰箱（免费吃剩饭）
- **校园**：操场（跑步）/ 技术群（水群）/ 图书馆（啃八股）/ 实验室（做项目）/ 小卖部（买零食）/ 宿舍（补觉、打游戏、蹭零食，晚上也能睡）
- **食堂**：大众菜 / 小炒 / 微波炉带饭 / 泡面 / 饮料机（酸梅汤）/ 奶茶（回心态）/ 水果摊（补健康）
- **办公室**：工位 / 茶水间 / 摸鱼刷手机 / 点外卖 / 咖啡机（回精力）/ 会议室（开周会练社交）/ 打印机（刷简历）
- **公园**：长椅（歇脚回精力）/ 喷泉（散步放松心态，免费休闲区，城东北，地铁可直达）
- **校园周边探索**：西门外夜市（**晚上才出摊**，撸串回饱食心态）/ 东侧观景台（免费登高回心态）/ 北墙外涂鸦墙（随机彩蛋台词）
- **时段节奏**：一天按时钟自动推进——上午（18s）→ 工作（22s）→ 午饭（16s）→ 晚上（25s）；晚上停驻，上床睡觉才进入下一天；进入晚上有概率触发一次晚间随机事件（约 70%）
- **交通方式**：地铁站 / 公交站交互 → 选目的地自动乘车前往（地铁快、公交慢）；乘车沿道路网行驶（支路 → 主路 → 市中心 → 主路 → 支路），全程不穿建筑；共享单车骑上后步行速度 ×2.5
- **城市交通设施**：每个十字路口双相位信号灯（东西向 ↔ 南北向互补，两方向绝不同时放行，红→绿→黄循环）；车辆按行驶轴向看对应信号，红灯/黄灯在停车线前停、绿灯通行，前方有玩家或行人会让行；**车灯齐全：转弯打橙色转向灯（闪烁）、减速/停车亮红色刹车灯、晚上（夜晚时段）自动开大灯**；玩家不能直接穿过车辆；过马路行人按信号通行——横穿道路车辆放行时在路边等灯、道路红灯（车辆停）时过马路，四个方向斑马线齐全；**行人横穿马路时车辆会减速（约 1/3 速度）并鸣笛提醒**（几何求交判定，只在车道交汇处触发，绿灯起步遇滞留路中的行人也让行鸣笛）；主干道两侧还有散步的路人
- **自主觅食**：饱食度低于 30 时，主角会自己冒气泡「肚子饿了…」走向最近的觅食点（家→厨房、食堂→便宜窗口、办公室→外卖）；
  精力低于 28 时自动走向床补觉
- **工作间隙**：工作时段点工位 / 茶水间可白拿一次效果（每天限一次，再点会被老板余光警告）

## 玩法核心

### 四大生存资源（互相制衡）
| 资源 | 作用 | 恢复方式 |
| --- | --- | --- |
| 精力 | 行动消耗，低精力做事事倍功半 | 睡觉、休息 |
| 心态 | 归零即崩溃（被拒、加班、挤地铁都会掉） | 娱乐、回家躺平 |
| 金钱 | 每周一交房租，没钱交直接game over | 实习/正式工资 |
| 技能 | 算法 / 八股 / 项目 / 社交 / 简历 | 刷题、复盘、做项目 |

技能成长公式带 **精力缩放** 与 **边际递减**：状态越好练得越快，越接近满分越难涨。

### 五个章节（约 26 周）
1. **大三暑期（4 周）**：海投实习，收到第一个实习 offer
2. **实习期（6 周）**：通勤上下班、午饭社交、赶需求，最终转正答辩
3. **秋招季（8 周）**：白天实习晚上刷题，笔试三轮面试拿正式 offer
4. **毕业入职（4 周）**：毕业手续、入职体检、试用期
5. **职场日常（4 周）**：日常打怪——白天上班、晚上刷题，走完 26 周结算结局

### 求职管线
投递 → 等回复（回复率由公司档次 × 简历质量 × 内推决定）→ 笔试（算法/八股答题）
→ 技术一面（限时答题）→ 项目二面（自动判定）→ HR 三面（谈薪对话，含 AI 工具话题）→ Offer

12 家公司（拼夕夕、字杰跳动、鹅厂互动、米哈油……）分三个档次，
大厂钱多但笔试面试更难、回复率更低。

### 每日循环
晨间消息 → 自由安排行程：走去公司 / 乘地铁、公交 / 骑共享单车上班
→ 工位赚钱、茶水间休息、点外卖 → 去食堂吃饭（大众菜 / 小炒 / 微波炉带饭 / 泡面）
→ 回家刷题、项目、社交、娱乐 → 随机晚间事件（7 个）→ 床上睡觉推进天数

### 角色互动
自由时段可「找人聊聊」：7 位 NPC（邻居赖哥、导师陈教授、妈妈、Mentor 张哥、
Leader 王总、产品小赵、HR 李姐）各有带分支的对话树，话题随章节变化——
从二姨的「AI 要取代程序员」到 leader 的「降本增效」，人人都在聊 AI。
聊天不消耗行动槽位；但每个 NPC 的对话效果每天只结算一次（同一天重复聊只走剧情、不再给心态/技能加成，防止反复白嫖）。

### 随机事件（7 个 · 晚间选项化）
- **深夜焦虑**：刷到「35 岁被裁」热搜睡不着——刷题压惊 / 吃夜宵 / 早点睡
- **深夜食堂**：夜宵吃不吃？——泡面加蛋（省）/ 撸串（贵但开心）
- **猎头来电**：深夜猎头画大饼——套点信息 / 婉拒
- **房东通知**：下月涨租 200——讨价还价 / 认栽
- **AI 工具分享**：邻居拉你研究新 AI 编程工具——认真研究 / 简单看看
- **游戏抽卡**：新版本抽卡活动——氪 30 抽一波 / 忍住
- **技术直播**：大牛直播讲 AI 全流程开发——全程做笔记 / 边玩边看

### 题库（10 题）
算法与八股之外，覆盖 **大模型八股**：Transformer 自注意力、Token、RAG、
Embedding、LoRA、KV Cache、temperature、微调 vs RAG，外加快排与 TCP 三次握手。

### 10 种结局
从「AI 时代的冲浪者 / 大厂 SSP 高开稳走」到「流落街头 / 心态崩溃回老家考公」，
由最终的心态 / 存款 / offer 档次与路线 flag 共同决定。

## 运行与操作

```bash
cargo run          # 开发模式运行（需联网首次拉取依赖）
```

- **鼠标**：点击地面行走；点击热点走近自动触发（床/书桌/书堆/厨房/电脑/手机…）
- **每日循环**：自由安排行程——走路或乘车去公司上班赚钱、去食堂吃饭、回家学习娱乐，晚上睡觉推进天数；周末可去校园
- **求职**：家里电脑投简历 → 每天自动推进 → 笔试会弹出答题 → 技术一面/项目二面/HR 面自动判定 → Offer
- **自主行为**：饱食 < 30 自动觅食，精力 < 28 自动补觉
- **失败条件**：心态归零崩溃 / 交不起房租；走完 26 周（5 章）结算结局
- **调试快捷键**：`1`-`5` 传送到家/校园/食堂/办公室/公园，`N` 推进一天，`J` 打开投简历面板，`T` 打开交通面板，`S` 手动存档，`U` 打开随机事件弹窗

### 新手学习路径（想改游戏从哪里动手）

本示例大量内容是**数据驱动的**——改数据就能改游戏，是最佳切入点：

| 想改什么 | 去改哪里 |
| --- | --- |
| 初始金钱 / 精力 / 心态 / 技能 | `game/resources.rs` → `PlayerStats::default()` |
| 地图大小 / 走路速度 / 总周数 | `game/resources.rs` 顶部常量（区域布局见 `*_CENTER`） |
| 技能成长速度 / 衰减曲线 | `game/resources.rs` → `skill_gain` / `change` |
| 随机事件内容（7 个） | `game/progression.rs` → `EVENTS` |
| 公司列表（12 家、三个档次） | `game/job.rs` → `COMPANIES` |
| 笔试题库（10 题） | `game/npc.rs` → `QUIZ` |
| NPC 与对话树（7 位） | `game/npc.rs` → `NPCS` |
| 城市里有哪些可互动的点 | `game/scenes.rs` → 各区域 `*_HOTSPOTS` 常量 + 全城交通站点 `CITY_STOPS` + 校园周边探索点 `CAMPUS_SURROUNDS` |
| 哪些东西会挡路（碰撞盒） | `game/art.rs` → 各 `spawn_*` 函数里的 `solid(...)`；街区楼在 `game/scenes.rs` 的 `spawn_street_buildings` |
| 热点点了之后发生什么 | `game/interactions.rs` → `do_action` 的 match 分支 |
| 每晚触发什么 | `game/progression.rs` → `EVENTS` 之外，还可看 `advance_day` |

想改**机制**（而不是数据）时：从 `game/mod.rs` 的系统注册列表入手，顺着某个系统名找到它的 `pub fn`，它就是一段独立的逻辑。

### Bevy 概念对照（ECS 四大概念 ↔ 本示例代码）

刚学 Bevy 时容易晕"组件/资源/系统"在哪，这里把核心概念和本示例对上号：

| Bevy 概念 | 是什么 | 本示例里的位置 |
| --- | --- | --- |
| 组件 Component | 挂在实体上的数据/标记 | `game/components.rs`（Hotspot/SealFill/GameRoot…） |
| 资源 Resource | 全局唯一的数据（每个游戏一份） | `game/resources.rs`（PlayerStats/GameClock/JobPipeline…） |
| 系统 System | 一段每帧运行的逻辑函数 | 各模块的 `pub fn`（如 `movement::move_player`、`hud::update_banner`） |
| 状态 State | 页面级流程（菜单/游戏/结局） | `router.rs` 的 `GameState` + `main.rs` 的 `OnEnter/OnExit/run_if` |
| 实体 Entity | 组件的集合，无显式类型 | 随处可见的 `commands.spawn((...))` |
| Query | 按条件批量取实体组件 | 系统参数里的 `Query<(&Hotspot, &Transform)>` |
| Single | 恰好一个实体的便捷查询 | `hud::update_banner` 等更新函数 |
| Local | 系统的私有持久变量（跨帧存活） | `modal::modal_ui`、`job::job_advance_system` |
| `.chain()` | 强制系统按顺序执行 | `game/mod.rs` 进入 Playing 的初始化链 |

阅读顺序建议：`main.rs` → `router.rs` → `game/mod.rs` → `game/resources.rs` → `game/interactions.rs`，再挑一个感兴趣的模块深入。
