# Web 前端与运行时学习笔记

本目录收集 TypeScript、Node.js、Bun 等 Web 相关的基础笔记（以 TypeScript 为主）。

## 目录导航

| 文件 | 说明 |
| --- | --- |
| [ts-基本.md](./ts-基本.md) | TypeScript 模块导出（ES Module / CommonJS） |
| [ts-二进制.md](./ts-二进制.md) | ArrayBuffer / DataView / 字节序 / 二进制转换 |
| [node-基本.md](./node-基本.md) | Node.js 安装、npm 与 TypeScript 基本用法 |
| [bun-基本.md](./bun-基本.md) | Bun 运行时常用命令 |
| [tslog/](./tslog/) | 代码学习项目：基础类型、函数、泛型、类、异步等示例（bun test） |

## 推荐学习顺序

1. 先看 [node-基本.md](./node-基本.md) 掌握 Node.js 与 npm。
2. 看 [ts-基本.md](./ts-基本.md) 理解模块导出。
3. 进阶看 [ts-二进制.md](./ts-二进制.md) 了解二进制数据处理。
4. [bun-基本.md](./bun-基本.md) 了解新兴的 Bun 运行时。
5. 动手练习 [tslog/](./tslog/) 学习项目。
